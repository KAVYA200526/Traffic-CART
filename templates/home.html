Dataset Information

Features:
  • Vehicle ID
  • Speed (km/h)
  • GPS Location
  • Signal Strength (dBm)
  • Packet Delay (ms)
Additional Features:
  • Congestion Level (%)
  • Available Bandwidth (MHz)
  • Contention Window Size
  • RSU Connection Status
Target Variables:
  • Priority Level (1-5) - Classification
  • Traffic Density (vehicles/km²) - Regression
ML Algorithms:
  • Support Vector Machine (SVM)
  • Random Forest
  • Hybrid MLP-KNN
