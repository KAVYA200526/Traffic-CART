Classification Performance Comparison
Support Vector Machine (SVM)

SVM with RBF kernel for non-linear classification of vehicle priority levels based on network and traffic parameters.

Random Forest

Ensemble method using multiple decision trees for robust priority classification with feature importance analysis.

  • Handles missing values well
  • Provides feature importance
  • Resistant to overfitting
Stacked RF-HST-LLR

Novel approach combining Stacked Ensemble Leaarning with RFC and Hybrid Subset Tree for enhanced prediction accuracy.

  • Ensemble capabilities
  • Local pattern recognition
  • Adaptive learning
Classification Metrics Explained
Accuracy

Overall correctness of the model in predicting priority levels across all classes (1-5).

Precision

Proportion of correctly predicted priority levels among all predictions for each class.

Recall

Proportion of actual priority levels that were correctly identified by the model.

F1-Score

Harmonic mean of precision and recall, providing balanced measure of model performance.

Regression Performance Comparison
Support Vector Regression (SVR)

  • Robust to outliers
  • Non-linear relationships
  • Sparse solutions
Random Forest Regressor

Ensemble method using multiple decision trees for robust traffic density prediction with feature importance analysis.

  • Handles non-linearity well
  • Feature importance ranking
  • Reduces overfitting

Novel approach combining Stacked Ensemble Leaarning with RFC and Hybrid Subset Tree for enhanced traffic density prediction.

  • Complex pattern learning
  • Local neighborhood influence
  • Improved generalization
Regression Metrics Explained
MAE

Mean Absolute Error: Average of absolute differences between predicted and actual traffic density values.

RMSE

Root Mean Square Error: Square root of the average squared differences, sensitive to larger errors.

R² Score

Coefficient of Determination: Proportion of variance in traffic density explained by the model (0-1).

Lower is Better

For MAE and RMSE, lower values indicate better performance. For R², higher values (closer to 1) are better.

Traffic Density Analysis Insights
Low Density (0-33 vehicles/km²)

Free-flowing traffic conditions with minimal congestion. High available bandwidth and low packet delays.

Medium Density (34-66 vehicles/km²)

Moderate traffic conditions with some network congestion. Balanced network resource utilization.

High Density (67-100 vehicles/km²)

Heavy traffic conditions with significant congestion. Limited bandwidth and increased packet delays.
