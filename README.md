# Traffic-CART: VANET Traffic Analytics

Traffic flow prediction and analytics in Vehicular Ad-hoc Networks (VANET) using CART (Classification and Regression Trees).

## Key Features
- VANET traffic data preprocessing and exploratory data analysis (EDA)
- CART decision tree model for traffic classification & regression
- Interactive dashboard UI built with Flask, HTML, and CSS

## Project Structure
- `app.py` / `routes.py` : Flask application endpoints
- `ml_pipeline.py` : CART model training and evaluation pipeline
- `templates/` : UI frontend pages
- `static/` : Stylesheets, scripts, and analytical plots

## How to Run
```bash
python app.py
```
